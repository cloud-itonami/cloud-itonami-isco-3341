# Operator Guide

## First Deployment

1. Define the office's staff roster, workflow/task board and supply
   catalog.
2. Define the workflow's registered supply-cost ceiling.
3. Run synthetic operating cases (task logging, scheduling, supply
   orders, HR-concern flags).
4. Enable human-reviewed sign-off for `:high`/`:safety-critical` actions
   (every `:flag-hr-concern`, every over-ceiling supply order).
5. Measure operating outcomes and audit coverage.

## Minimum Production Controls

- registered staff roster and workflow board, kept current
- safety-critical escalation path for HR concerns and over-ceiling orders
- provenance for all operating records
- human review for every HR concern and every over-ceiling supply order
- audit export for all gated actions

## Certification

Certified operators must prove that the governor gates every
safety-critical robot action, that safety-critical risks (in particular
any HR concern) escalate to humans, and that no automated path can ever
finalize a disciplinary action, termination or performance-review
determination.
